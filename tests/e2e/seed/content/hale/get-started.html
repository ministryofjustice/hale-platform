How to log in

The Website Builder team will set you up as a user when we create a new site. Look out for an email. Remember to check your spam folder.

Enter your username and password in the WordPress log-in screen.

Dashboard

When you first log in, you’ll see the WordPress dashboard. This is the back-end of your website.

Pages

Create and edit pages for your website.

Media

Store images, documents, videos and other media that you’ll use across your site.
