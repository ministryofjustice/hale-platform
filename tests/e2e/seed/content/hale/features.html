Website Builder is a publishing platform built on WordPress using the multisite feature. This allows us to more efficiently manage a whole collection of websites, regularly updating and improving features available to all.

Current features

Website Builder is flexible, modular and creative.

Website Builder has been developed based on a modular system of content blocks. Whereas many WordPress themes have fixed templates and fixed fields to produce a fixed layout, Website Builder gives you more control over how you want to build your page.

Simply add different blocks to create different layouts for your page.
